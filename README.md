# About `expansion-internet`

**`expansion-internet`** is a feature branch for **`emerald-expansion`** that integrates the Mobile Adapter library (libma) to add internet connectivity features. Currently, only a GTS system has been developed. **`expansion-internet`** should be used in conjunction with [MA_Server](https://github.com/Artrios/MA_Server) which handles all requests sent by the game.
